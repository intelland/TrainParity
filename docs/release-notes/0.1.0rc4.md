# TrainParity 0.1.0rc4 release notes

`0.1.0rc4` is a bounded comparison-policy and diagnostic prerelease motivated
by independent external adoption. Those adoptions exposed API and diagnostic
needs; this release does not claim that the external projects pass TrainParity
or add them to the formal compatibility matrix.

## Resume comparison policy

`check_resume()` now accepts an explicit comparison policy. Exact comparison
remains the default. A tolerance is always declared by the user and is never
inferred or tuned by TrainParity. The same declared policy governs baseline
self-consistency and candidate resume comparison.

## Exact mismatch diagnostics and report schema

Exact floating-point and complex mismatches now include numerical error
magnitudes while remaining exact failures. Stable resume comparison metadata
caused the global machine-report schema to advance from schema 1 to schema 2.
Consumers should continue to reject unknown schema versions rather than infer
compatibility.

Install this release candidate with:

```bash
pip install trainparity==0.1.0rc4
```

## Unchanged boundaries

This release adds no new check or framework adapter. It does not weaken exact
comparison, infer root causes, tune tolerances, expand the compatibility
matrix, or change the four `PASS` / `FAIL` / `ABSTAIN` / `ERROR` outcomes.
