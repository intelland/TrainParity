# TrainParity 0.1.0rc2 release notes

`0.1.0rc2` is a small prerelease polish following independent external use of
`0.1.0rc1`.

Relative to `0.1.0rc1`:

- scheduler-free accumulation cases can construct `TrainingState` without
  explicitly writing `scheduler=None`;
- the README documents an explicit CPU-only PyTorch installation path;
- source-checkout pytest instructions explicitly install the development
  dependencies required by the repository pytest configuration.

Install this release candidate with:

```bash
pip install trainparity==0.1.0rc2
```

This release adds no TrainParity check or framework adapter. It does not expand
the declared PyTorch support range or make a new compatibility claim. Resume,
accumulation, and sample-coverage semantics are unchanged, as are the
`PASS` / `FAIL` / `ABSTAIN` / `ERROR` definitions.
