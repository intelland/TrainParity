# TrainParity 0.1.0

TrainParity 0.1.0 is the first non-prerelease release of the alpha-quality
project. It promotes the behavior, public API, and machine-report schema
verified through `0.1.0rc5`; it does not add comparison semantics or expand
the supported framework scope.

## Included checks

- Resume equivalence across a real process exit and fresh-process load.
- User-declared full-batch versus gradient-accumulation equivalence.
- Finite sample-ID coverage under four explicit policies.

All checks retain distinct `PASS`, `FAIL`, `ABSTAIN`, and `ERROR` outcomes.
Reports identify the first observed divergence or policy violation, not an
inferred root cause. Exact comparison remains the default; numeric tolerance
is used only when the caller explicitly supplies `ToleranceComparison`.

## Install

```bash
pip install trainparity==0.1.0
```

CPU-only users can avoid resolution of the default CUDA-enabled PyTorch wheel
by installing a validated CPU wheel first:

```bash
python -m pip install torch==2.7.0 --index-url https://download.pytorch.org/whl/cpu
python -m pip install trainparity==0.1.0
```

Package metadata requires CPython `>=3.11,<3.12` and permits
`torch>=2.7,<2.14`. Release validation explicitly covers CPU PyTorch 2.7.0,
2.10.0, and 2.13.0 on Python 3.11; intermediate versions in the declared
range were not independently validated. Machine reports remain schema 2.

## Boundaries

TrainParity is not a universal bug detector, root-cause analyzer, sandbox,
checkpoint manager, distributed launcher, or framework adapter. User training
code executes with the caller's permissions, and only trusted repositories
and checkpoints should be executed or loaded.

See the repository README, API reference, validation evidence, limitations,
and security policy for the complete user contract.
